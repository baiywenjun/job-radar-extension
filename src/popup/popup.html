设置

模型 API OpenAI 兼容

Key 只存在本机浏览器里，不同步、不写日志、不进入网页上下文。内容脚本永远读不到它。

高级参数（温度 / 超时 / 输出上限 / 单价）
单价只用于成本统计，代码里不内置任何价格，避免过期。

判定行为 成本与可信

同一条 JD 只调用一次，之后直接读本地缓存。超限或限流只停自动判定，面板仍会显示本地词库结果。

达到上限后不再自动请求；需要时在面板上点「手动放行一次」。触发 429 会自动冷却 5 分钟。
