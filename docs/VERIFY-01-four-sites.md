# 0.3.0 四站真机验证清单

> 这份清单是 S5 的交付物之一。自动化测试能保证"逻辑对"，但保证不了"选择器在当前版页面上还能命中"——那件事只能在登录态的真站上做。
>
> 用法：按表逐行跑，把结果填进「实测」列。任一项打 ❌ 就把该行的现象 + 面板「复制诊断」的内容一起记下来。

## 准备

1. `chrome://extensions` → 岗位雷达 → 点 ↻ 重新加载，确认卡片版本是 **0.3.0**
2. 打开弹窗 → ⚙ → 确认 Key 与模型名（`deepseek-chat`）、单价已填，点一次「测试连接」
3. 判定标准至少建两条（用来验"换标准"那一条），必要项写一条 JD 里通常**不会**出现的词（用来验"标准要求但原文没提"）
4. 清空一次判定（设置 →「清空判定」），从零开始记录

**通过判据**

- 职位 / 公司 / 薪资 / 城市 四项与页面**肉眼一致**（薪资允许格式统一为 `18-25K`，但数字必须一致）
- 经验为空是可以接受的（很多岗位不写），但**不能是错的**（比如把"在校"当经验）
- 字段右侧来源标签不是 `未取到`；若是 `列表匹配` / `字形混淆`，检查器里应有对应的打折提示
- JD 正文里没有「取消收藏」「微信扫一扫」「投递简历」「查看更多」这类按钮文案
- BOSS 的薪资若显示 `未取到 · 字形混淆`，说明私有区字形映射失效了 —— 记下来，这是需要更新的信号（不要接受一个"看起来正常"的错数字）

**记录口径**：抽取失败率 = 字段错误或未取到的岗位数 ÷ 12。

## 二、判定链路（每站第 1 个岗位做一遍）

| # | 检查项 | 期望 | 实测 |
|---|---|---|---|
| 13 | 打开岗位后无需点击 | 先出本地规则结果，几秒后换成模型结论 | |
| 14 | 底部来源行 | 写明 `模型 <模型名> · tokens · 秒数` | |
| 15 | 证据逐字核对 | 引用对不上的 chip 变灰并写「未能核实」 | |
| 16 | **同岗位二次打开** | 底部显示 `缓存 · N 分钟前`；**不新增轨迹**（缓存不计费也不落新记录） | |
| 17 | 今日调用数 | 第 16 步前后**不变** | |
| 18 | 切到另一个岗位再切回 | 旧请求被取消；面板不显示上一个岗位的结论 | |
| 19 | 改一次标准（保存使版本 +1）后重开 | 缓存失效、重新请求、历史里出现新的一条 | |

第 16 条是 0.3.0 之前一直没验到的点：上一版 `verdict` 缺 `key` 字段，落库静默失败，缓存永不命中。现在缓存真正生效了，**必须确认"同岗位第二次不发请求"**。

## 三、判定历史（0.3.0 新功能，集中在一个岗位上验）

选第 1 个岗位（BOSS），按顺序做：

| # | 操作 | 期望 | 实测 |
|---|---|---|---|
| 20 | 弹窗 → 岗位库 → 点职位名 | 检查器里出现「判定历史」段 | |
| 21 | 看汇总 | `判过 1 次`（首次）；不出现 `跨 N 个标准` | |
| 22 | 看轨迹条 | 1 个圆点，颜色与档位一致，下方是分数 | |
| 23 | 回页面点「重新判定」（检查器右上角） | 历史变 2 条；逐条列表最新在上；第二行出现 `↑N` 或 `↓N` | |
| 24 | 回页面复制一段 JD 改动后重新保存，再判一次 | 出现 `正文有改动` 标记 | |
| 25 | 面板顶部换一条判定标准后再判 | 出现 `换了标准` 标记，该行变化列写 **`不可比`**（不是 0） | |
| 26 | 汇总行 | 变成 `判过 3 次 · 跨 2 个标准 · 正文改过 1 次`，明细给两个标准的首末分数 | |
| 27 | 设置 →「清空判定」后重开检查器 | 历史与最近一次判定一起消失，不残留"孤儿轨迹" | |
| 28 | 升级前判过的老岗位（如有） | 历史段写明「0.3.0 之前判的，之后再判一次就会开始积累」，**不显示成"从没判过"** | |

第 25 条最容易做错也最容易看出问题：跨标准的两条如果被算出差值，那是纯噪声。

## 回填之后

把这份表格（含 ❌ 行的诊断文本）贴回来，按这个优先级处理：

1. **字段错**（第 1–12 行）→ 改 `src/content/adapters.js` 的选择器，或补几何/字号兜底
2. **字形混淆**（第 1–12 行备注）→ 重新采字符码，更新 `extract.js` 里的私有区映射
3. **判定链路**（13–19）→ 看诊断里的【模型判定】段
4. **历史视图**（20–28）→ 属于逻辑问题，一般能直接补一条测试复现
